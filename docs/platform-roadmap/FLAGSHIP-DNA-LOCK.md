# Flagship DNA Lock — remaining 12 skins

## heritage (education-premium) — `ed`
EDITORIAL MAGAZINE
- Masthead with issue/date/dept
- Multi-column article body
- Pull-quote bands
- No equal card grids; reading flow first

## atelier (ecommerce-premium) — `ec`
PRODUCT RUNWAY
- Full-bleed product stage (edge-to-edge)
- Sticky purchase rail
- Lookbook filmstrip
- No corporate metrics strip

## nexus (saas-enterprise) — `se`
APP SHELL
- Left app sidebar + main canvas
- Product UI chrome as first viewport
- Not a marketing hero

## kinetic (creative-portfolio) — `cp`
HORIZONTAL FILMSTRIP
- Horizontal scroll work stages
- Vertical only for colophon/contact
- Giant type as labels, not centered SaaS hero

## estates (real-estate-premium) — `rep`
PROPERTY DOSSIER
- Split: listing index | detail dossier
- Specs sheet, not feature cards
- Search as utility, not hero CTA theatre

## forest (restaurant-signature) — `rs`
TASTING MENU SPINE
- Single vertical menu document
- Course numbers, prices, notes
- Atmosphere via type/paper, not card hero

## prism (prism-aurora) — `pr`
ASYMMETRIC BENTO
- Mosaic tiles of unequal size
- No centered hero block
- Color fields as structure

## obsidian (obsidian-noir) — `ob`
TYPOGRAPHY MANIFESTO

## pulse (pulse-fintech) — `pu`
LIVE TICKER / STREAM

## forge (forge-industrial) — `fg`

## citadel (citadel-trust) — `ct`

## lumina (lumina-wellness) — `lu`
